心聊 ChatMate PWA — 整合離線聊天助手 v5
=========================================

新增整合功能：
- 本機對話記憶：保存最近 10 則輸入與選用回覆。
- 情緒辨識：以繁體中文關鍵字初步辨識難過、生氣、焦慮、開心、尷尬；可手動指定情緒。
- 語氣排序：溫柔體貼、自然口語、輕鬆幽默、堅定有界線、可愛曖昧。
- 自動推薦會將訊息關鍵字、近期對話、情緒及語氣加權，排序最相關的前 5 則離線範本。
- 提供查看記憶、清除記憶控制。
- Service Worker 快取版本更新為 chatmate-v5。

隱私與限制：
- 記憶只存在目前瀏覽器的 localStorage，不會自行上傳；清除網站資料會移除記憶。
- 情緒辨識與推薦排序是規則式功能，不是真正 AI 語意理解；反諷、隱含語意或複雜情緒可能判斷不準。
- 請避免保存密碼、身分證號或其他高度敏感資料。
- PWA Service Worker 需 HTTPS 或 localhost。部署後先在線上重新載入一次，再測試離線。
- 真正 AI 服務需透過安全後端，勿將 API 金鑰放在公開前端。
